## GitHub Pages 发布建议

1. 新建 GitHub 仓库。
2. 将本目录文件提交到 `main` 分支。
3. 在 GitHub 仓库设置中开启 Pages：`Settings -> Pages -> Deploy from a branch -> main / root`。
4. 发布后访问：`https://<owner>.github.io/<repo>/`。
